# 02 — UI 디자인 지침

## 레퍼런스
사용자가 제공한 `image.png`(NARNIA LABS 웹사이트 스크린샷)를 시각적 레퍼런스로 사용합니다. **원본 이미지/브랜드/로고/텍스트를 복제하지 말고** 다음 시각 언어만 재해석합니다.

### 추출할 시각 요소
- 거의 검정색 전체 배경, 흰색 대형 영문 헤드라인
- 매우 얇고 낮은 대비의 가로·세로 그리드 선
- 좌측 정렬 내비게이션과 넓은 여백, 정밀한 편집디자인
- 중앙의 큰 제품 이미지 프레임, 차가운 회보라색 조명
- 작은 모노스페이스 보조 레이블, 가는 테두리, 절제된 포인트
- 섹션 사이 교차선/십자 표시, 카드의 미세한 호버 반응

## 디자인 토큰
```css
:root {
  --bg: #0a0a0b;
  --surface: #141416;
  --surface-raised: #1b1b1f;
  --line: #2b2b30;
  --text: #f4f4f5;
  --muted: #a4a4ad;
  --accent: #aaa5df;
  --accent-strong: #c4beff;
  --danger: #f1a2a2;
  --font-sans: 'Pretendard', 'Noto Sans KR', system-ui, sans-serif;
  --font-mono: ui-monospace, SFMono-Regular, Consolas, monospace;
  --content-max: 1440px;
  --header-height: 72px;
}
```
- 텍스트/배경 대비 WCAG AA 이상 목표. 본문 16px 이상, 보조 12px 이상.
- 한글 헤드라인은 굵고 간결하게, 영문 `AIRMOD`는 큰 시각적 타이틀로 사용.
- 로고는 자체 제작한 간단한 문자형 AIRMOD. 원본 레퍼런스 브랜드 사용 금지.

## 화면별 레이아웃
### 1) 랜딩
- 상단 고정 헤더: AIRMOD 로고 / 모델 선택 / 모딩 시작 / 저장한 구성 / 서비스 소개.
- 히어로: 좌측 작은 기술적 레이블, 중앙 큰 에어소프트 이미지, 하단 대형 `AIRMOD` 타이포.
- CTA `모딩 시작하기`, 보조 문구 `에어소프트 외장 커스터마이징 추천`.
- 얇은 그리드 라인은 장식용으로만 사용, 인터랙션 방해 금지.

### 2) 설정 화면
- 데스크톱: 좌측 조건 폼(40%), 우측 모델 미리보기(60%).
- 모바일: 모델 이미지 → 조건 입력 → 하단 고정 추천 버튼.
- 카드 선택 시 얇은 보라색 외곽선과 체크 상태 표시.

### 3) 결과 화면
- 대표 유사 이미지(출처/유사 이미지 고지) + 우측 비용/중량 KPI.
- 아래 추천 부품 표, 추천 이유, 장단점, 부품 교체 영역.
- 이미지 3개 이내 갤러리, 이미지 클릭 시 원본 출처 새 탭 열기(`rel=noopener noreferrer`).

## 반응형 기준
- 모바일: 0~767px, 1열, 헤더 축약, 큰 터치 영역(최소 44px).
- 태블릿: 768~1199px, 필요 시 2열.
- 데스크톱: 1200px 이상, 그리드 기반 2열 및 여백 확장.
- 375px 화면에서 가로 스크롤이 없어야 함.

## 애니메이션
- 히어로 진입: opacity 0→1, translateY(16px→0), 450~650ms.
- 카드 호버: border-color, translateY(-3px), 180ms.
- 섹션 진입: IntersectionObserver로 한 번만 reveal, 350~500ms.
- 추천 계산 중: 스켈레톤/로딩 텍스트, 장시간 무한 스피너 금지.
- 비용·무게 갱신: 숫자 변경 250ms, 단 `prefers-reduced-motion: reduce`면 즉시 변경.
- 스크롤 연동 과도한 패럴랙스/강제 스크롤/점멸 효과 금지.

## 접근성
- `lang="ko"`, 의미 있는 heading 순서, 모든 입력에 label.
- 키보드 Tab/Enter/Space로 모든 기능 조작 가능.
- 상태 변경은 `aria-live="polite"`로 공지.
- 장식 그리드는 `aria-hidden="true"`.
- 이미지에 설명적 alt, 검색 실패 시 텍스트 대체.

## 완료 기준
- 제공된 레퍼런스의 분위기는 유지하되 브랜드 복제 없음.
- 모든 페이지 한국어, 375/768/1440px 정상 표시.
- reduced-motion과 키보드 탐색 정상 동작.
